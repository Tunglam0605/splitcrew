# SplitCrew v0.2.0-alpha plan

Goal: harden the local mobile MVP before owner-host networking.

## Scope

- Replace SharedPreferences JSON persistence with SQLite.
- Add schema versioning and migration entry points.
- Use UUID identifiers for trips, members, and expenses.
- Persist entity timestamps and versions needed by future multi-device sync.
- Add edit flows for trip, member, and expense records.
- Add member removal safety rules.
- Add expense detail/audit view.
- Keep domain, split, and settlement engines independent from storage/UI.
- Preserve Android CI build and regression tests.

## Non-goals

- Owner-host networking.
- Receipt OCR.
- Bank API integration.
- Cloud synchronization.
